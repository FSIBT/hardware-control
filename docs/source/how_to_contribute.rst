How to contribute
=================

The source code can be found at::

  https://bitbucket.org/berkeleylab/hardware-control/

We use `pre-commit <https://pre-commit.com/>`_ to run check and format the code, so please install *pre-commit* using::

  pip install pre-commit

and then run::

  pre-commit install

from within the git repository of hardware control.

Feedback and pull requests are welcome, including PRs for new hardware.
